### **STEP 3: Save the GitHub Push Script**

**File:** `push-to-github.sh`

**Content:**
```bash
#!/bin/bash
set -e
echo "🚀 Pushing I'm Just a Build to GitHub..."
echo "Target: https://github.com/coreyalejandro/tlc-artifacts"
echo ""

# Check if git is installed
if ! command -v git &> /dev/null; then
    echo "❌ Git is not installed. Please install Git first."
    exit 1
fi

# Check if we're in the right folder
if [ ! -f "package.json" ]; then
    echo "❌ Error: package.json not found"
    echo "   Make sure you're in the im-just-a-build folder"
    exit 1
fi

# Initialize git if not already done
if [ ! -d ".git" ]; then
    echo "📦 Initializing Git repository..."
    git init
fi

# Configure git (if not already configured)
if ! git config user.email &> /dev/null; then
    echo "⚠️  Git email not configured"
    read -p "Enter your Git email: " git_email
    git config user.email "$git_email"
fi

if ! git config user.name &> /dev/null; then
    echo "⚠️  Git name not configured"
    read -p "Enter your Git name: " git_name
    git config user.name "$git_name"
fi

# Create .gitignore
cat > .gitignore << 'EOF'
node_modules/
dist/
out/
*.log
.DS_Store
.vscode/
.idea/
EOF

echo "✅ .gitignore created"

# Add all files
echo "📁 Adding files to Git..."
git add .

# Commit
echo "💾 Committing..."
git commit -m "Initial commit: I'm Just a Build - Neo-soul constitutional animation"

# Add remote
if ! git remote get-url origin &> /dev/null; then
    echo "🔗 Adding GitHub remote..."
    git remote add origin https://github.com/coreyalejandro/tlc-artifacts.git
else
    git remote set-url origin https://github.com/coreyalejandro/tlc-artifacts.git
fi

# Push to GitHub
echo "☁️  Pushing to GitHub..."
git push -u origin main || git push -u origin master

echo ""
echo "✅ SUCCESSFULLY PUSHED TO GITHUB!"
echo "📍 Repository: https://github.com/coreyalejandro/tlc-artifacts"
```

### **STEP 4: Run the Push Script**
```bash
bash push-to-github.sh
```

### **STEP 5: Enter Credentials**
When prompted, enter your GitHub username and password/token.

## 🔐 Authentication Note

GitHub now requires **personal access tokens** instead of passwords:
1. Go to GitHub → Settings → Developer settings → Personal access tokens
2. Generate a token with "repo" permissions
3. Use that token as the password when pushing

**Or** use SSH if you have that set up.
